# **ServiceConnect**

ServiceConnect is an all-in-one platform designed to connect service seekers with skilled freelance workers effortlessly.

Save time searching for reliable handymen, plumbers, or contractors; instead, the platform provides location-aware service discovery along with transparent quotes and reviews to help you get jobs done efficiently.

The goal of this Website is to eliminate the hassle of finding trustworthy local professionals across multiple platforms, allowing customers to post their job requirements and hire verified workers in just a few clicks!

It is a full-stack web application built to help customers post service requests, receive competitive bids from local workers, and track job progress in real time.
It offers AI-powered problem diagnosis and price estimation, direct cloud image verification for before-and-after work, and a secure rating and review system to ensure high-quality service delivery.

**Current Completed Features Include:**
* Authentication & Google OAuth
* Role-Based Dashboards (Customer & Worker)
* Location-Aware Job Request Creation & Management
* Quotation & Bidding System
* AI-Powered Problem Analysis & Cost Estimation
* Before & After Cloud Image Uploads
* Ratings & Reviews System

**Current Planned Features Include:**
* Real-Time In-App Messaging
* Integrated Payment Gateway
* Push & Email Notifications
* Worker Verification & Background Checks
* Advanced Booking & Scheduling Calendar
* Dispute Resolution Center
